# 壁打ち記録：設計v0 → v1（2026-11-09）

3体のAIに、別々の立場から設計v0へ反論させた結果と、その採否です。法務の論点は弁護士確認前の論点出しです。

## 1. 求人マーケティング／応募者心理

| 反論 | 採否 | v1での形 |
|---|---|---|
| 根拠ガードで収入例を消すと「いくら？」に答えられない | 採用 | 単価の幅×件数×日数の試算を全店共通に。出所と確認日つき |
| 事実がない欄を消すと小さな店ほど薄い | 採用 | 店→グループの順で埋め、出所ラベル（店の数字／グループの数字）を表示 |
| 応募の手間と面談までの待ちで熱が冷める | 一部採用 | LINE応募・即時予約リンク欄を追加。フォーム4項目化はフォーム側の宿題 |
| 初期費用まとめ表で応募が減る | 採用（表は残す） | 「最低単価でも約○件で回収」を自動計算して隣に表示 |
| 「週1からOK」と「繁忙期に稼働できない人は不向き」が矛盾 | 採用 | 「週1日からOK」を削除。働き方3択（副業／両立／本業）で試算を切替 |
| 雇用語を全部消すと検索で見つからない | 一部採用 | タイトル・説明文は「募集」「エアコンクリーニング職人」で検索語を確保。本文の雇用語は止める（法務を優先） |
| 鮮度切れでビルド失敗→応募ゼロ | 採用 | 失敗させず、古い欄だけ隠す／停止モードに |
| 価値観が冒頭だと引かれる | 採用 | 価値観は代表セクションへ移動 |
| KPI不足 | 採用 | 段ごとの離脱・初回連絡時間・すっぽかし・90日稼働・辞退理由を追加 |
| 小さな店の強みが言葉になっていない | 採用 | P1ヒアリングに代表の原体験・30秒メッセージを必須化 |
| 地域版を絞ると流入が減る | 不採用 | 法務・技術とも量産地域版はリスク大。JobPostingと媒体で流入を補う |

## 2. 法務・コンプライアンス

| 論点（リスク） | 採否 | v1での形 |
|---|---|---|
| 道具・リース・業者紹介が業務提供誘引販売取引（特商法51条以下）に当たりうる（高） | 採用 | `business_model` の4フラグ。1つでも true なら確認記録がないと公開不可。ページに「販売・リース・紹介をしていない」旨を明記 |
| 研修・同行が契約の前（労働者性）（高） | 採用 | 手順を「面談→契約→研修」に固定。逆ならビルド停止 |
| 雇用の言葉の混在（フリーランス法12条指針）（高） | 採用 | NG語辞書（terms.yml）で生成後の全文を検査 |
| 単価なし・手取り・年収モデル（高） | 採用 | 単価の幅を必須に。実例は9項目そろわないと非表示。「手取り」禁止 |
| 「あと3名」に時点がない（中〜高） | 採用 | 「○年○月○日時点」を必ず表示、30日で自動非表示 |
| フッターの表記違い・募集主体のあいまいさ（中〜高） | 採用 | 「募集を行う事業者（業務委託の発注者）」に変更。正式名称・番地・報酬・確認日・「ページ制作は本部」 |
| 実績の数字が店かグループか（中） | 採用 | 数字ごとに scope・出所・確認日 |
| 募集のない地域の地域版（中） | 採用 | 地元の事実3つ以上の地域だけ |
| 声・写真の同意と流用（中） | 採用 | 同意日・同意範囲・店IDが必須。他店の声はビルド停止 |
| 独立支援→加盟勧誘（中） | 採用 | 独立費用の扱いを明記する欄。LP内で売上予測を出さない |
| 契約期間・解除（低〜中）、支払60日（低） | 採用 | 契約期間・終了の欄、payment_days ≦ 60 を検査 |
| 景品表示法は基本的に及ばない（低） | 参考 | 中心はフリーランス法12条と特商法54条 |

## 3. 静的サイト量産・SEO・運用

| 反論 | 採否 | v1での形 |
|---|---|---|
| ビルド失敗では古いページが残る | 採用 | Actionsで毎日ビルド＋停止モード |
| 1社1リポジトリはやめてモノレポ＋サブパス | 採用 | `sites/<slug>/` を1リポジトリに並べる |
| 独自ドメインを最初から | 保留 | 本部の判断待ち（今すぐアクション2） |
| baseSalary は出さない | 採用 | JobPostingから除外 |
| JobPostingの中身 | 採用 | CONTRACTOR・identifier・validThrough自動・datePosted固定・発注者名 |
| 初期費用の購入先をスキーマで管理 | 採用 | `vendor: 自由|指定` 必須 |
| 地域版は条件つき | 採用 | 3事実以上・canonical自己参照・sitemapはindex対象のみ |
| 60社で同文が並ぶ | 次版 | 固有文の比率チェックは v2 |
| 表示速度 | 採用 | base64廃止・画像別ファイル・Webフォント読み込みなし（2.2MB→約40KB） |
| フォーム連携と計測 | 一部採用 | co/area/utm の引き継ぎ・cta_click。送信完了ページでの generate_lead はフォーム側の宿題 |
| チェックの実装 | 採用 | 必須項目・用語・根拠・鮮度・特商法・研修順序・支払日を build.py で検査。エラー文は日本語 |
| data は純YAML | 採用 | `data.yml` に変更 |
