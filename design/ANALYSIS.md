# 分析：タスカル求人LP（tasukaru-recruit）

対象：https://tasukarutaoka-cpu.github.io/tasukaru-recruit/
取得：2026-11-09（リポジトリ最新コミット 571a9e0「求人LPをVC型訴求に改修」）

## 1. ひとことで言うと

条件の一覧表ではなく、**「Zoom面接で正直に話す内容を、先に全部ウェブに出したページ」**。
応募者が頭の中で順番に抱く不安を、上から順に消していく並びになっている。

## 2. 構成（12セクション＝不安が消える順番）

| 順 | セクション | 応募者の頭の中の問い | 使っている材料 |
|---|---|---|---|
| ヒーロー | 未経験OK！プロとして働く | 「自分にもできる？いくら？」 | 月収目安チップ、収入実例1行、実写写真、CTA＋「応募＝即契約ではない」 |
| 01 | 価値観と仕事の中身 | 「どんな会社？どんな仕事？」 | 価値観3つ・8つの言葉、作業内容、**需要の波グラフ** |
| 02 | 応募資格 | 「自分は対象？」 | 免許だけ、教習所通学中も可 |
| 03 | 募集人数・背景 | 「なぜ募集？怪しくない？」 | 増員理由、年間1万件・30名体制・口コミ5.0/450件 |
| 04 | 給与（報酬） | 「本当に稼げる？」 | 単価×件数の式、収入例、年収モデル2本（600万/350万） |
| 05 | 勤務地 | 「地元でできる？」 | 周辺エリア制、地域版リンク |
| 06 | 1日の流れ | 「1日どう動く？」 | 3件の日／2件の日のタイムライン、作業写真 |
| 07 | 休み | 「休めるの？」 | 自分で決める |
| 08 | 契約形態・条件 | 「落とし穴は？」 | 業務委託の明示、車両・道具、**向いていない人** |
| 09 | 応募〜独り立ち | 「応募したら何が起きる？」 | 6ステップ |
| 10 | 研修 | 「未経験で本当に大丈夫？」 | オンライン＋同行5日・12〜16件 |
| 将来 | 自分の店を持つ道 | 「その先は？」 | 独立支援（任意） |
| 11 | FAQ | 残った細かい疑問 | 9問 |

| 締め | まずは話を聞いて | 「応募のハードル」 | Zoom面談、隠さず話す宣言 |

## 3. 信頼をつくっている7つの装置

1. **先回りの正直さ**：閑散期（1月〜4月半ば）、向いていない人、完全歩合で保証なし、を自分から書いている
2. **「応募＝即契約ではない」の反復**：CTAのたびに心理的ハードルを下げている
3. **計算式の見える化**：「単価×件数＝報酬」で、根拠のない高収入アピールに見えない
4. **具体的な1日**：時刻つきタイムライン2パターンで、働く自分を想像させる
5. **研修の数字**：動画本数・同行日数・件数まで出していて「研修完備」が口先でない
6. **組織の実績**：年間1万件・30名・口コミ5.0/450件で「個人ではなく店の信頼で受ける」
7. **人の顔**：代表の人柄（猫5匹・赤ちゃんを抱く写真）と価値観で、会社の体温を伝える

## 4. 弱点（量産側で直すべき点）

### 応募者目線
- **初期費用が散らばっている**：道具10〜12万円、軽自動車必須、リース、レンタカー…が3か所に分散し、合計いくらで始められるかが一目で分からない
- **収入例の根拠が薄い**：「初月21日で53万円」「手取り62万円」に、件数・単価帯・経費の扱い・地域・時期が書かれていない。年収モデルの前提（件数×日数）もない
- **FAQの重複**：道具代と車の話がFAQと条件表で二重、独立の話が3回
- **鮮度表示がない**：「あと3名」がいつ時点の数字か分からない。ずっと「あと3名」に見える
- **スタッフの声が汎用的**：地域版でも同じ2件。千葉版の「千葉で働く人の声」も中身は全国と同じ

### 言葉づかい（業務委託として）
- 「給与」「勤務地」「勤務時間」「シフト制」「休日休暇」「入社6ヶ月目」「手取り」など**雇用の言葉が混在**。業務委託なのに雇用と誤認させる言葉になっている（詳しくは法務レビュー参照）

### 技術・集客
- **2.2MBの1ファイル**：画像33枚をbase64で埋め込み。スマホで重く、表示が遅い
- **地域版約200ページが検索に出ない**：`#a3_5` のようなハッシュ切替をJSで描画しているため、Googleは1ページとしか見ない。sitemapも1URLだけ
- **自動生成の地域版が薄い**：市名を差し替えただけの文で、内容は全エリアほぼ同じ（検索エンジンからは量産ページ扱いされやすい）
- **構造化データなし**：Googleしごと検索（JobPosting）に載る準備がない。OGP画像もない
- **計測が見えない**：GA4とClarityはあるが、CTAクリックや流入元別の応募がフォームまでつながって見える設計になっていない（`?area=` だけ）

## 5. 量産で「残す」もの・「変える」もの

| 残す（型にする） | 変える（量産側で直す） |
|---|---|
| 12セクションの順番 | 雇用の言葉→業務委託の言葉に統一 |
| 正直に書く欄（閑散期・向かない人） | 初期費用を1つの表に集約し合計を出す |
| 「応募＝即契約ではない」の反復CTA | 収入例は根拠項目がそろわないと載せない |
| 計算式・タイムライン・研修の数字 | 募集枠・数字に「確認日」を出し、古くなったら公開を止める |
| 代表の顔と価値観 | 地域版は「地元の事実」がある所だけ実ページで作る |
| 1社1ブランドの色・写真 | 画像は別ファイル化・軽量化、JobPosting・sitemap対応 |
